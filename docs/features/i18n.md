## Overview

The bot uses a **split-only** i18n loader. All localized strings live under
`app/resources/i18n/` as manifest-driven JSON fragments. There is no legacy
monolith fallback. The legacy files `app/resources/strings/fa.json` and
`app/resources/strings/en.json` were permanently **deleted** (2026-06-11).

For the full architecture breakdown (fragment layout, TextService internals, CI enforcement),
see [../architecture/i18n_architecture.md](../architecture/i18n_architecture.md).

## Split Fragment Layout

```
app/resources/i18n/
  manifest.json          ← fragment registry
  fa/                    ← Persian fragments
    common.json
    labels.json
    panels/
      group.json
      developer.json
      ...
    features/
      playback.json
      ...
    system/
      errors.json
      ...
  en/                    ← English fragments (same structure)
```

Fragment layout and manifest fields (`path`, `namespaces`) are documented in
[app/resources/i18n/README.md](../../app/resources/i18n/README.md).

Validate the tree (read-only):

```bash
python scripts/split_i18n_resources.py --check
python scripts/split_i18n_resources.py --check --verbose
```

Running the script without flags performs the same read-only validation.
It checks JSON validity, fragment existence, duplicate leaf-path collisions,
FA/EN leaf-path parity, and that all leaves are strings. Enforced in CI via
`tests/test_i18n_hybrid_split.py`.

Verify code/resource key coverage (read-only):

```bash
python scripts/check_i18n_usage.py
python scripts/check_i18n_usage.py --verbose
```

This AST-scans `app/**/*.py` for `t()` / `label()` usages and confirms every
literal key — plus every enumerated key of each registered dynamic family
(`DYNAMIC_ALLOWLIST` in the script) — exists as a string leaf in both FA and
EN. Unregistered dynamic f-string patterns fail the run. Enforced in CI via
`tests/test_i18n_usage_coverage.py`.

## TextService API

```python
from app.utils.i18n import TextService, texts, t, label

# Singleton usage
texts.t("fa", "common.buttons.back")             # → "بازگشت"
texts.t("fa", "start.welcome", mention="Ali")    # → format kwargs applied
texts.t("fa", "missing.key")                     # → "[missing:missing.key]"
texts.t("fa", "common.buttons")                  # → "[invalid:common.buttons]" (not a leaf)

# Module-level shortcuts
t("fa", "start.welcome")          # uses AUTO_LANG context resolution
label("fa", "broadcast_mode", "groups")  # → localized label or raw value
```

## Auto-Language Resolution

`AUTO_LANG` is a sentinel that resolves to the current request's language via a
`ContextVar`. Legacy `"fa"` handlers automatically upgrade to the request
language if it differs.

```python
from app.utils.i18n import AUTO_LANG, set_current_lang, reset_current_lang

token = set_current_lang("en")
# ... handler code uses t(AUTO_LANG, key) → resolves to "en"
reset_current_lang(token)
```

## Adding New Strings

1. Add the key to the relevant fragment under `app/resources/i18n/fa/` and `en/`
2. Ensure the fragment path is registered in `manifest.json` (existing groups
   do not need new fragment entries)
3. Run `python scripts/split_i18n_resources.py --check` before commit
4. If the key belongs to a dynamic f-string family, also register it in
   `DYNAMIC_ALLOWLIST` in `scripts/check_i18n_usage.py` and run
   `python scripts/check_i18n_usage.py`

Do **not** add strings to a removed `app/resources/strings/` monolith.

## Manifest Structure

```json
{
  "version": "1.0",
  "languages": ["fa", "en"],
  "fragments": [
    { "path": "common.json", "namespaces": ["common"] },
    { "path": "panels/group.json", "namespaces": ["panels.group"] },
    ...
  ],
  "deprecated_keys": []
}
```

Fragment order matters: duplicate leaf paths across fragments are a **fatal**
error at runtime and in `--check`.

## Failure Behavior

- Missing or invalid `manifest.json` → `I18nResourceError` at load time
- Missing language directory or fragment file → `I18nResourceError`
- Duplicate leaf path across fragments → `I18nResourceError`
- Missing translation key at lookup time → `[missing:key.path]` (unchanged)
- Non-string leaf at lookup time → `[invalid:key.path]` (unchanged)

## Rollback

Restore split fragments from git. There is no monolith fallback path.
