- `/resume` - Resume paused playback
- `/skip` - Skip to the next song
- `/stop` - Stop playback and leave the voice chat
- `/queue` - Show the current song queue
- `/help` - Display all available commands

Find the `config.json` file in the application folder. Use any text editor (like Notepad) to open it. Here you can adjust:

- **Session Name:** A name for your user session

- **Default Volume:** Initial volume level for playback
- **Language:** Change the interface language (currently supports English, Spanish, and Russian)

### 🔧 Performance Tuning

If you experience lag or buffering:

1. Reduce the "Max Sessions" value in config
2. Lower the "Default Volume" setting
3. Close unnecessary programs running in the background
4. Check your internet connection speed

## 🛟 Troubleshooting Common Issues

### Problem: Application Won't Start

- Make sure you extracted all files from the ZIP archive
- Check that your Windows version meets the requirements
- Temporarily disable antivirus software and try again
- Run the application as administrator (right-click, select "Run as administrator")

### Problem: Bot Not Responding

- Verify your bot token is correct in the configuration file
- Ensure your internet connection is stable
- Restart the application completely
- Check that the bot is not blocked by Telegram

### Problem: Audio Cuts Out Frequently

- Lower the "Max Sessions" value in configuration
- Move closer to your router for better Wi-Fi signal
- Use a wired Ethernet connection if possible
- Close bandwidth-heavy applications (like video streaming)

### Problem: Cannot Connect to Voice Chat

- Make sure you have permission to join the voice chat
- Check that the voice chat is still active
- Try rejoining the voice chat manually
- Restart the application and try again
